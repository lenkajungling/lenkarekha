# lenkarekha.com

Web Lenky Rekhy: jóga, dech, freediving.

- Stránky (`*.html`, `sluzby/*.html`) se generují skriptem `_src/build.py`. Texty upravuj tam a pak spusť `python3 _src/build.py`.
- Vzhled: `assets/style.css`, chování (menu, rozvrh, formuláře, parallax): `assets/main.js`, fotky: `assets/img/`.
- Hostováno na GitHub Pages, doména v souboru `CNAME`.
